# Intelligent-Agent-Project

This repository contains my Pirate Intelligent Agent project completed as part of my Emerging Trends in Computer Science coursework. The goal of this project was to apply reinforcement learning and neural network concepts to train an agent capable of navigating a maze and finding treasure through experience.

The project provided the maze environment, supporting classes, and portions of the starter code, while I was responsible for implementing the learning components that allowed the agent to improve its decisions over time. Seeing the agent learn from its successes and failures helped me better understand how machine learning systems solve problems that would be difficult to program with traditional logic alone.

This project reinforced the importance of breaking complex problems into smaller pieces, testing different approaches, and continuously improving a solution based on results. It also helped me better understand the role computer scientists play in developing technology that solves real-world problems and improves the way people work and interact with technology.

As artificial intelligence continues to grow, developers have a responsibility to create systems that are reliable, secure, and trustworthy. This project strengthened my understanding of both the technical and ethical responsibilities involved in developing intelligent systems.

Through this project, I gained experience with reinforcement learning, neural networks, artificial intelligence, Python programming, testing, and problem solving.
