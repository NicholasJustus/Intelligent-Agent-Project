# Intelligent-Agent-Project

## Project Reflection

### Briefly explain the work that you did on this project. What code were you given? What code did you create yourself?

For this project, I was given the maze environment, supporting classes, and starter code. My responsibility was to complete the reinforcement learning portions of the project so the pirate agent could learn how to navigate the maze and find the treasure. I worked on the code used to train the agent and improve its decision-making through repeated training runs.

### What do computer scientists do and why does it matter?

Computer scientists solve problems by designing and developing software and technology solutions. Their work matters because technology impacts almost every part of our lives, including communication, healthcare, transportation, education, and entertainment. Computer scientists help create tools that make tasks easier, faster, and more efficient.

### How do I approach a problem as a computer scientist?

I approach problems by first understanding the requirements and then breaking the problem into smaller pieces. From there, I test different solutions, analyze the results, and make improvements until I reach the desired outcome. This project reinforced the importance of experimentation and continuous improvement when solving complex problems.

### What are my ethical responsibilities to the end user and the organization?

My ethical responsibility is to create software that is reliable, secure, and functions as intended. Users trust developers to protect their information and provide accurate results. I also have a responsibility to be honest in my work, follow professional standards, and consider how technology may affect both users and the organization.
